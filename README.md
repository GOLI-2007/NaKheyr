# NaKheyr

A Java-based network messaging application developed as a personal project.

### Features
- Real-time messaging between users
- Offline message delivery
- User profile management
- Client-server communication
- Multithreaded network connections

### Technologies
- Java
- Socket Programming
- TCP/IP
- Multithreading
- Object Serialization

### Project Structure
- `client/` – Client-side functionality
- `server/` – Server and connection management
- `shared/` – Shared classes and data structures
